# Raio de Borda

Base: **6px** — equilíbrio entre técnico (Linear: 4px) e amigável (Notion: 8px). Escala proporcional derivada de uma única variável `--radius`.

---

---

## Uso recomendado por componente

| Componente | Raio |
|---|---|
| Inputs, selects, botões | `rounded-lg` (8px) |
| Cards | `rounded-xl` (12px) |
| Dialogs, modais | `rounded-2xl` (16px) |
| Badges, chips | `rounded-full` (9999px) |
| Tooltips | `rounded-xs` (3px) |
| Kbd | `rounded-xs` (3px) |
| Avatars | `rounded-full` |
| Toasts (Sonner) | `rounded-xl` |
