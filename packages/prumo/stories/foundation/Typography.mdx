# Tipografia

O Prumo usa duas famílias: **Inter** (`font-sans`) no corpo e em UI densa — formulários, tabelas, texto pequeno — e **Zen Kaku Gothic New** (`font-display`) em títulos de marketing e destaque. É a mesma gótica japonesa usada na identidade pessoal do autor, substituindo a Hiragino Sans original (fonte de sistema da Apple, não licenciada para web).

## Uso recomendado

| Contexto | Classe | Exemplo |
|---|---|---|
| Título de página | `text-2xl font-semibold tracking-tight` | Dashboard |
| Título hero / marketing | `font-display text-4xl md:text-5xl` | Prumo |
| Título de card | `text-base font-semibold tracking-tight` | Vendas do dia |
| Corpo | `text-sm` | Descrição do produto |
| Label de campo | `text-sm font-medium` | Nome do negócio |
| Legenda / hint | `text-xs text-muted-foreground` | Campo obrigatório |
| Badge / tag | `text-xs font-semibold uppercase tracking-wider` | ATIVO |
